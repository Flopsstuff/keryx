# Keryx

A voice interface to [Hermes](https://github.com/NousResearch/hermes-agent), the sibling of
[RaspiDR](https://github.com/Flopsstuff/raspidr) on different hardware. Speech recognition and synthesis may run
locally on the same Raspberry Pi as Hermes itself.

*Keryx* (κῆρυξ) is Greek for a herald — the one who speaks aloud for Hermes.

Work in progress.
